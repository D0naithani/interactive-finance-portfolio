# Upwork portfolio entries

Use each as a separate portfolio project. Role: **Finance Systems & Automation Developer**. All descriptions below are under 600 characters. Add the actual hosted URL followed by its route only after publication is verified. Images are actual screenshots of the working demos, not client work.

## 1. Financial Data Quality & Reconciliation Engine

Built an interactive reconciliation demo with a Python FastAPI and pandas backend. It compares ledger and bank records, quarantines duplicate IDs, flags missing transactions and calculates signed variances with configurable tolerances. Users can search records, filter exceptions and export the current control report to CSV. Includes automated calculation and API tests. Independent portfolio project using synthetic data; not a client deliverable.

Skills: Python, pandas, FastAPI, Data Cleaning, Financial Analysis.

Demo route: `/#quality`. Image: `quality.jpg`.

## 2. Investor Operations & Capital Allocation Console

Built a Python-backed investor reporting console covering commitments, paid-in capital, uncalled balances and distribution scenarios. Users can filter fictional funds, inspect investor accounts and export allocation reports. The allocation engine uses paid-in capital and largest-remainder rounding so distributions reconcile exactly to the cent. Includes automated tests. Independent synthetic-data portfolio demo; the pro-rata scenario is not a contractual investment waterfall.

Skills: Python, Financial Reporting, Financial Analysis, FastAPI, pandas.

Demo route: `/#investor`. Image: `investor.jpg`.

## 3. M&A SaaS Product & Deal Pipeline Studio

Built a conceptual M&A product workspace combining an interactive deal pipeline with Python APIs for financial screening. Users can filter stages, compare revenue multiples, inspect probability-weighted pipeline values and open deal-level next actions and acceptance criteria. Connects product requirements, workflow architecture and financial analytics in one working demo. Independent project using fictional companies and metrics; not a reproduction of a client's product.

Skills: Product Strategy, Business Analysis, Python, Financial Analysis, FastAPI.

Demo route: `/#gro`. Image: `gro.jpg`.

## 4. Founder KPI Dashboard & Revenue Scenario System

Built an interactive founder dashboard with Python FastAPI and pandas calculations for MRR, annualised revenue, customer churn and acquisition cost. Users can filter acquisition channels and reporting periods, adjust growth and churn assumptions, inspect a six-month forecast and export monthly revenue bridges. Includes tests for known calculations, filter behaviour and forecast boundaries. Independent portfolio demo using synthetic data; scenarios are illustrative, not validated forecasts.

Skills: Python, Data Visualization, Business Intelligence, Financial Analysis, pandas.

Demo route: `/#kpi`. Image: `kpi.jpg`.
